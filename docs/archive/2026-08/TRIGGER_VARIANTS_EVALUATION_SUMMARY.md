## 🎯 实验设计

### 研究假设
**触发器的视觉特征（颜色/形状/位置）可能影响后门学习的稳定性，存在方差更小的设计。**

### Baseline问题
- **sharps25**: Cond ASR = 68.3% ± **51.8pp**（方差极大）
- 3个种子: 100.0% / 8.6% / 96.4%（最差种子几乎失败）
- 原因: 投毒样本少（1 episode/55帧），后门学习依赖SGD随机性

## 🐛 关键问题与修复

### 问题1: 评测脚本颜色参数缺失 ✅ 已修复

**发现时间**: 2026-08-16 13:20

**问题描述**:
- `experiments/robot/libero/run_libero_eval.py` 第453行硬编码:
  ```python
  fill = (255, 0, 0, a)  # 强制红色
  ```
- 导致blue/green/white变体评测时触发器颜色不匹配
- 触发率 = 0%，无法正确评测Cond ASR

**影响范围**:
- ❌ blue seed42: 触发率0%（无效评测）
- ❌ green seed42: 触发率0%（无效评测）
- ❌ white 所有种子: 未来会遇到相同问题

**修复方案** (已实施):
1. 添加 `--visual_backdoor_dot_color` 参数到评测脚本
2. 修改 `scripts/eval_dropvla.sh` 支持环境变量 `DOT_COLOR`
3. 更新调用方式:
   ```bash
   DOT_COLOR=blue bash scripts/eval_dropvla.sh
   ```

**验证计划**:
